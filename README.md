# Customer Delinquency Risk: EDA, Modeling Plan and Collections Strategy

Exploratory data analysis and strategy work for predicting credit delinquency, completed as part of the **Forage (Tata) GenAI Powered Data Analytics Job Simulation**.

> This is a job-simulation project, not work for a real company. The dataset is provided by Forage for simulation use only and is **not** included in this repo.

## Project overview

Geldium (a fictional financial services company) wants to identify customers at risk of delinquency. The project covers four tasks:

1. **Exploratory data analysis and risk profiling:** data quality checks, cleaning, statistical tests and visuals (`delinquency_eda.py`)
2. **Predictive modeling plan:** model choice, justification and an evaluation and fairness strategy
3. **Business report:** a two-page report with insights and a SMART recommendation for the Head of Collections
4. **AI-driven collections strategy:** an executive deck on how the system works, agentic AI roles, responsible AI guardrails and business impact

## Dataset

500 customers, 19 columns: demographics, income, credit score, credit utilization, missed payments, loan balance, debt-to-income ratio, employment status, card type, location, and 6 months of payment history. Target: `Delinquent_Account` (16% delinquent, 80 of 500).

## Key findings

- **Data quality issues found and fixed:**
  - `Employment_Status` had 6 inconsistent labels, standardized to 4.
  - `Credit_Utilization` and `Debt_to_Income_Ratio` were stored as fractions, not percentages.
  - `Month_1` to `Month_6` were text, not numeric codes.
  - 4 customers had utilization above 100%.
- **Missing values:** Income (7.8%), Loan_Balance (5.8%) and Credit_Score (0.4%), handled with median imputation plus missing-value flags.
- **Weak signal:** every numeric correlation with the target is below 0.05, and no Mann-Whitney U or chi-square test was significant. The dataset appears to be synthetic or randomly generated.
- **Directional patterns (not significant):** Business cards (21%) vs Platinum (12%), Unemployed (19%) vs Retired (11%).
- **Takeaway:** always predicting "not delinquent" is already 84% accurate, so models should be judged on recall, F1 and PR-AUC instead of accuracy.

## How to run

```bash
git clone https://github.com/KamleshRathour55/delinquency-risk-eda.git
cd delinquency-risk-eda
pip install -r requirements.txt
# put Delinquency_prediction_dataset.xlsx in the data/ folder
python delinquency_eda.py
```

The script prints the analysis results, saves charts to `eda_plots/` and writes `delinquency_cleaned.csv`.

## What the script does

1. Loads the data and checks size, types and summary statistics
2. Checks for missing values, duplicates, inconsistent labels and out-of-range values
3. Cleans labels and units, imputes missing numbers and encodes payment history
4. Engineers features: late and missed month counts, payment score, recent 3-month score, loan-to-income ratio
5. Univariate analysis: distributions, boxplots, IQR outlier counts, category counts
6. Bivariate analysis against the target: Mann-Whitney U and chi-square tests, delinquency rate by group
7. Multivariate analysis: correlation heatmap, pairplot, employment by card type heatmap
